# Biscoito Studio Code

A modern, extensible code editor inspired by VS Code built with React, TypeScript, and Electron.

## Features

- 🎨 Modern dark theme with beautiful UI
- 📁 File explorer with drag-and-drop support
- ✏️ Monaco Editor integration
- 🖥️ Integrated terminal
- 🔍 Global search and command palette
- 🎛️ Extensible plugin system
- ⌨️ Customizable keyboard shortcuts
- 💾 Auto-save functionality
- 🌈 Theme customization

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Project Structure

```
src/
├── components/        # React components
├── hooks/            # Custom React hooks
├── layouts/          # Layout components
├── stores/           # Zustand stores (state management)
├── styles/           # Global styles
├── types/            # TypeScript types
├── utils/            # Utility functions
└── App.tsx           # Main App component
```

## Technologies Used

- React 18
- TypeScript
- Zustand (State Management)
- TailwindCSS
- Monaco Editor
- Electron
- Vite
